# TDK v1.1 実装・検証報告

検証日: 2026-10-15（日本時間）。Node.js v24.18.1、Windows、ローカルChrome。

## 1. 実装した機能

- 単発チェーン型テンプレート。発動中に同じ種類の有効なツムを3個以上つないで離すと特殊消去し、スキルを終了する。
- SL1〜6ごとに時間・必要チェーン長・周辺消去距離・コイン補正・回収率を設定できる。
- InputRouter → onChainStart → 既存チェーン追跡 → onChainCommit → ClearPipeline の接続を利用。
- 成功・不正入力・受付失敗をすべて処理済みとして返し、通常消去との二重処理を防止。再入・重複リリース・キャンセル済みジェスチャーも検証。
- スキル時間切れ・ゲーム時間切れ・リセット・終了で途中のチェーンを解除。消去受付失敗後は新しいジェスチャーで再試行できる。
- 共通契約と操作別契約を分離。従来の `testTsumContract` は共通＋タップとして互換維持。

## 3. 生成方法

```sh
npm run tsum:new -- newTsum
npm run tsum:new -- newChainTsum --template=chain
npm run tsum:validate
npm run test:tdk
```

どちらも `definition.js`、`skill.js`、`visuals.js`、`image.svg`、`skill.test.mjs` の5ファイルを生成し、カタログ登録を自動実行する。ID・重複・既存ファイル保護・サブツム検証を維持。不明なオプションは生成前に拒否する。

## 4. 開発専用ツム

`chainTestTsum`: `developmentOnly: true`、手動のみ対応、CPU／最強モード未対応、通常選択から除外。SL1〜6、3/4/5種類を起動できる。スキル発動演出、`CHAIN READY` と残り秒数、消去の波紋、終了表示がある。

試験URL: `http://127.0.0.1:8765/?tdk=1&tsum=chainTestTsum&sl=1&types=3`。

6個を消去する既知の盤面ではコイン5、ゲージ3（回収率0.5）。通常チェーンでは同じ6個でコイン5、ゲージ6。各消去の呼び出し元が `skill` または `chain` の一方だけであることも検証した。

保存隔離は両試験ツムの進行・設定・AI学習・対戦記録・終了処理を自動検証。ブラウザの開発セッションでもStorageの読み書きは0件だった。
