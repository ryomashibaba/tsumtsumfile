# AUTO CHAIN SL6

開発専用・保存なし。基点はTDK v1.1 `ab66ad3`。main・既存PR・公開環境は変更していない。

## Windowsで遊ぶ

この作業フォルダーの `PLAY-AUTO-CHAIN.cmd` をダブルクリックする（Node.jsが必要）。
ブラウザが開いたら左上の「スキル充填」→ Space。手動でなぞるか、画面下の「最強 OFF」をクリックする。
終了時は起動したコンソールでEnterを押す。専用サーバーだけを終了する。

直接起動する場合は、このフォルダーで `node scripts/serve.mjs` を実行し、
`http://127.0.0.1:8765/?tdk=1&tsum=autoChain&sl=6&types=5` を開く。`types=3/4/5` 対応。
SL1〜5は起動・発動を拒否する。TDK検証用の6要素テーブルは契約互換のための値で、SL1〜5の実装ではない。

## 実装

- コスト22、実時間10秒。通常ゲーム時計も進む。開始時のボムは爆発させず削除。
- 既存の接続判定（余白4）で同色の単純経路を探索。10個以上の最長経路を選び、同長は探索順。
- 落下中も毎フレーム再判定。自動・手動とも瞬間消去、回収10%、ボム生成なし。
- 自動消去と重なる手動入力はキャンセル。自動回数のみカウント。
- 星型発光粒子を物理から分離し最大480個に制限。右上カウンターが発光・拡大し、中央へ移動して5倍表示。
- フィニッシュは実際のツムを追加し、一時的な小サイズの収容盤面へ移動。全対象が天井下に入り、さらに200ms以上待ってから重複なしのランダム瞬間消去。
- フィニッシュ中は専用の一時収容処理で物理を管理する。恒久的な物理やチート設定は変更しない。
- フィニッシュは消去個数と同じ1チェーンのスコア・コイン。大型ツムもフィニッシュ対象として1個ずつ数える。終了まで回収10%を維持。
- 終了・キャンセル・リセットでサイズと上限を復元。結果画面はフィニッシュ完了を待つ。
- 最強AIはスキル発動中のみ、全ツムの中心が盤面下半分（中央線上を含む、y >= 360）にある3〜9個の自主チェーンに制限。候補がなければ待機し、実行直前にも位置と長さを再確認する。10個以上のスキル自動消去と手動操作は従来どおり。フィニッシュ中は入力を停止し、終了後に通常制御へ戻る。

## 制限と未検証

最長単純経路の探索には1回あたり120,000探索ノード・約4msの予算がある。未確定の短い経路を最長として消去することはない。予算超過フレームは自動消去せず、次フレームの最新盤面で再探索する。したがって非常に複雑な配置では、10個以上つなげられてもそのフレームで発動できない場合がある。4msは探索のソフト予算であり、GCや隣接表構築を含む実行時間の厳密な上限ではない。

具体的再現: [search-budget-fixture.json](qa/auto-chain/search-budget-fixture.json) の45座標を全同色・通常サイズで配置する（乱数seed431、2枚目の生成盤面）。接続距離96.8px、`maxMs: Infinity`でも120,001探索ノードで未確定になる。これは物理整列前の合成配置で重なりを含む。通常の落下で配置が変われば再探索する。既存物理のp95基準未達も残るため、性能QAを完全合格とは扱わない。

物理タッチ端末、他ブラウザ、長時間のゲームバランス評価は未実施。
